# 📊 PostgreSQL Internship Assignment

Welcome to the PostgreSQL Internship Assignment repository created by **Adarsh Mishra**. This repository contains complete SQL scripts for database creation, table schema setup, sample data insertion, and analytical business queries.

---

## 📌 Project Overview

This project demonstrates core relational database concepts using PostgreSQL, including:
- **Database Architecture**: Structuring relational tables with Primary and Foreign Key constraints.
- **Data Manipulation**: Inserting structured datasets for Customers, Products, and Orders.
- **Advanced Querying**: Writing SQL queries to generate business insights (Sales trends, Customer Segmentation, Inventory analysis).

---

## 📁 Repository Structure

| File Name | Description |
| :--- | :--- |
| `database_adarsh.sql` | Contains `CREATE TABLE` and `INSERT INTO` scripts for Customers, Products, and Orders. |
| `query_adarsh.sql` | Contains analytical SQL queries for data retrieval and business problem-solving. |

## 🛠️ Tech Stack & Tools

- **Database Management System**: PostgreSQL
- **Database Client**: pgAdmin 4 / psql
- **Version Control**: Git & GitHub
